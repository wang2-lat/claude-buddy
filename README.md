# Claude Buddy 🐣

**An open-source CLI companion pet inspired by Claude Code's hidden BUDDY feature.**

Anthropic hasn't released it yet. So we built our own. Open source. For everyone.

## Features

- 🥚 **Gacha hatching system** — 18 unique species with rarity tiers
- ✨ **Shiny variants** — 1/256 chance for special appearance
- 📈 **Stats & leveling** — XP from coding activity, evolves at milestones
- 💬 **Personality** — Each pet gets a unique AI-inspired personality
- 🎮 **Interactions** — Feed, play, train, and bond with your buddy
- 📊 **Mood system** — Happiness, hunger, energy affect behavior
- 🏆 **Achievements** — Unlock badges through coding milestones
- 💾 **Persistent** — Pet state saved between sessions

## Install

```bash
pip install claude-buddy
# or
python3 buddy.py
```

## Usage

```bash
buddy              # Check on your pet
buddy hatch        # Hatch a new egg
buddy feed         # Feed your buddy
buddy play         # Play with your buddy
buddy train        # Train to gain XP
buddy stats        # View detailed stats
buddy achievements # View achievements
```
